# Phase 05.4 Carrier B X4 Checkpoint Procedure

## Stop Boundary

This procedure is prepared for the user. Automated Plan 02, Plan 03, and Plan
04 qualification is complete. X4 runtime acceptance is not claimed. The
executor must stop before installation, X4 launch, game controls, or SETA.

Do not use an existing save. Use a disposable Creative Custom campaign with
vanilla, owned DLC, and Live Galaxy only. Do not read, copy, inspect, or modify
save files during evidence collection.

## One-Time Preparation

1. Verify all candidate digests while X4 is closed.
2. Copy only `dist/live-galaxy-carrier-b/extensions/live_galaxy` into the X4
   user extensions directory. Keep the package itself unchanged as the source
   copy.
3. In X4 extension settings, enable Live Galaxy and disable Protected UI.
   Disabling Protected UI is required for the native UI module and may disable
   protected/online features; this loss is accepted by ADR-LG-009.
4. Create a new private evidence directory outside the repository and outside
   the X4 installation. Restrict it to the current user. Use it as
   `<private-data-dir>` below.
5. Retain a copy of `manifest.json`, `carrier-b-limits.json`, and all bridge
   output in that directory. Never retain a private artifact only in a
   temporary directory.

The external bridge invocation is the same in PowerShell, Command Prompt, and
other shells when each placeholder is replaced by one quoted absolute path:

<!-- markdownlint-disable MD013 -->

```text
live-galaxy-bridge.exe --data-dir <private-data-dir> --limits-file carrier-b-limits.json
```

Offline readback must run only after the bridge is stopped:

```text
live-galaxy-bridge.exe --readback --data-dir <private-data-dir> --section-key carrier_b_realtime_sample --section-revision <revision>
```

<!-- markdownlint-enable MD013 -->

Expected readback is one typed record with getter `GetCurRealTime`, semantics
`opaque_runtime_number`, the requested revision, and a receipt. It must contain
no action or mutation command.

## Ordinary Window

After B1 through B6 pass, run at normal speed for 10 real minutes. Sample once
per real minute and retain the current bridge output and an offline readback at
minutes 1, 5, and 10. Pass only if:

- X4 remains responsive and the bridge remains bounded;
- at least 18 of the expected 20 callback opportunities commit a revision;
- every committed revision has exactly one record and one receipt;
- no duplicate revision, third delivery attempt, action, or mutation appears;
- process working sets do not show monotonic unbounded growth across all ten
  samples.

Stop immediately on any failed condition. Fully exit X4 before changing the
installed candidate or any DLL/Lua/ABI/contract file.

## Sustained SETA Window

Only after the ordinary window passes, run SETA for 20 real minutes. Sample
once per real minute and retain offline readbacks at real minutes 1, 5, 10, 15,
and 20. Pass only if:

- the game remains controllable and exits SETA normally on user input;
- every sample shows finite bridge/storage growth and no stalled callback for
  more than 35 real seconds;
- each readable revision has exactly one typed fact and one receipt;
- bridge restart once at real minute 10 recovers within 35 seconds without a
  duplicate publication;
- no mutation operation, third delivery attempt, raw prompt, secret, or
  machine-local path appears in public diagnostics.

Stop SETA and exit X4 immediately on a crash, freeze, repeated missed deadline,
duplicate publication, or any mutation-shaped traffic.

## Restart Rules

- The compatible external bridge may restart independently.
- A bridge binary, limits, or protocol change requires stopping the old bridge
  before replacement.
- Any loaded DLL, Lua, ABI, or game-facing contract change requires a full X4
  exit and restart. Never hot-replace the native image.
- Do not use UI reload, save reload, or a save file as a substitute for a full
  process restart in this checkpoint.

## Evidence Handoff

Record each row in `05.4-carrier-b-evidence.md` as observed or failed. Include
the package logical ID, all four digests, exact wall-clock durations, startup
order, revision identities, readback text, working-set samples, and stop reason.
Do not mark runtime acceptance complete until every B row and both timed
windows pass.
