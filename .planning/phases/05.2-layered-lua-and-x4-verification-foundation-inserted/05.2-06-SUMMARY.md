## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Canonicalized PowerShell JSON timestamps before signature verification**

- **Found during:** Task 1 GREEN.
- **Issue:** `ConvertFrom-Json` materialized ISO timestamps as `DateTime`, which changed their culture-sensitive string form and invalidated a correct root signature.
- **Fix:** Canonicalized `DateTime` and `DateTimeOffset` values back to exact UTC ISO text before hashing and verification.
- **Files modified:** `tools/x4-verification/local-attestation.psm1`.
- **Verification:** `owner_authority_contract.ps1 -Case root-delegation`.
- **Committed in:** `4632aad`.

**2. [Rule 1 - Bug] Bounded derived override identifiers without truncation collisions**

- **Found during:** Post-task security review.
- **Issue:** A maximum-length valid owner decision ID could produce an override ID rejected by the shared evaluator.
- **Fix:** Derived a fixed-length SHA-256-based override ID and enforced canonical ID syntax in the common exact evaluator.
- **Files modified:** `tools/x4-verification/local-attestation.psm1`, `tools/x4-verification/new-owner-override.ps1`.
- **Verification:** All three focused authority suites.
- **Committed in:** `83c4554`.
