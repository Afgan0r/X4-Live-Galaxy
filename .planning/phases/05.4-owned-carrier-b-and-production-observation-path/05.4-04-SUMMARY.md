## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Lifetime correctness] Added Lua state-close guardian**

- **Found during:** Task 2 pending-I/O `lua_close` RED.
- **Issue:** The wrapper had no Lua 5.1 finalizer, so an abandoned session kept
  the native module loaded and its worker ownership live.
- **Fix:** Added a `newproxy` userdata guardian that calls exactly one
  `api.close(token)`; successful explicit close disarms it.
- **Files:** `live_galaxy_carrier.lua`, focused Lua and actual-host tests.
- **Commit:** `c9c7dba`.
- **Approval:** Parent explicitly authorized this direct-consumer extension as
  T-05.4-MEM while preserving D-12/D-13.

**2. [Rule 2 - Stale handle isolation] Added a reload generation fence**

- **Found during:** Task 2 real unload/reload scenario.
- **Issue:** A fully unloaded DLL recreated the deterministic registry at
  generation 1, allowing a prior image token to alias a fresh handle.
- **Fix:** Kept `HandleRegistry::new()` deterministic for unit contracts while
  ABI open initializes a process/DLL-load generation from a nonzero OS seed and
  a checked next-generation process value. Malformed, zero, and exhaustion
  paths fail closed.
- **Files:** `lua_generation.rs`, `lua_operations.rs`, lifecycle/ABI tests.
- **Commit:** `c9c7dba`.
- **Approval:** Parent explicitly authorized the narrow native extension.

**3. [Rule 1 - Plan 03 defect] Used the canonical encoded batch identity**

- **Found during:** Task 2 actual DLL-to-bridge integration.
- **Issue:** The actual batch included transport epoch but pending feedback used
  a parallel shorter ID, so the exact bridge receipt was rejected.
- **Fix:** Decode the identity from the already assembled immutable batch; no
  second formatter or protocol change was added.
- **Files:** `producer_feedback.rs`, producer receipt regression/support.
- **Commit:** `c9c7dba`.
- **Approval:** Parent explicitly authorized the narrow direct fix.

**4. [Rule 3 - Rust size contract] Split the receipt regression mechanically**

- **Found during:** Task 2 strict source-size lint.
- **Issue:** Adding the RED regression made `producer_contract.rs` 215 lines.
- **Fix:** Moved the receipt regression into
  `producer_receipt_contract.rs`; the original file is 195 lines with no new
  responsibility.
- **Commit:** `c9c7dba`.
