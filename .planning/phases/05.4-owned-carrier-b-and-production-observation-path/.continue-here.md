# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] RECONNECT IS A PROTOCOL FENCE: rotating only `connection_generation` is insufficient. The wire `transport_epoch` must change, the incomplete candidate must be discarded, and the replacement bridge must receive bootstrap first.
- [ ] REAL PRODUCER EVIDENCE: a raw transport or manually encoded bootstrap test does not prove recovery. Drive `Producer + NativeTransport + replacement bridge` through pending start, batch, completion, and commit-before-disposition loss.
- [ ] RETAINED CANDIDATE: a package built in an isolated worktree disappears when that worktree is removed. Rebuild and verify the stable main-checkout candidate after the final product commit.

**Do not proceed until all boxes are checked.**
