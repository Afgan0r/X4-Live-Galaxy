# Phase 05.4 Plan 03: DLL-Owned Native Producer Summary

The native DLL now owns the complete Carrier B observation envelope, canonical digest, completion certificate, and immutable retry lifecycle, while Lua performs one bounded opaque X4 getter call through a typed ABI 2 adapter.

## Accomplishments

- Implemented a bounded Rust producer that emits bootstrap, section-start, immutable-batch, and completion messages compatible with the Plan 02 receiver.
- Added the exact ten-operation ABI 2 surface with copied table inputs, strict type and extra-field rejection, panic containment, and no Lua-side hashing or wire construction.
- Added the exact owned-module loader plus observation, scheduler, and runtime adapters that reserve before sampling, call `GetCurRealTime` once, and never repeat the getter during retry.
- Bound retry to two byte-identical attempts through 5,000 ms, then paused fail-closed on ambiguity, terminal feedback, stale identity, or exhaustion.
