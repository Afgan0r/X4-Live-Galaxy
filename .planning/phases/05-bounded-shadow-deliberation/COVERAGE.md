# Phase 05 API Coverage Declaration

Phase 05 does not integrate a public external API, SDK, or runtime service.

The only real-model mechanism in scope is an explicit, developer-run local
Codex CLI subscription benchmark harness behind the same typed provider port as
the deterministic fake. It is excluded from the X4 bridge, normal runtime,
normal CI, credentials, and public API configuration. Its evidence is benchmark
evidence only; Phase 8 owns any quality thresholds.

This declaration exists because the phase legitimately uses the terms provider,
CLI, and harness, which can trigger a broad API-coverage detector.
