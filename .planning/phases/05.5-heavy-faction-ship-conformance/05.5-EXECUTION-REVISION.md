## Runtime risk and evidence contract

A synchronous X4 native call cannot be interrupted by the collector's timer. The
initial profile therefore bounds admitted calls, allocations, selected objects,
attempts, retained state and admission duration; it does not certify a maximum
duration for a call already executing. The agent supplies a finite, locally tested
nonzero proposal and explains this residual risk before owner approval. Unknown
latency is a measurement target, not an impossible precondition. A freeze or limit
breach stops later admissions and closes neither gate. Changes to the package or
limits after measurement require relevant reruns, not reuse of mismatched evidence.

The owner performs only game actions and explicit risk/threshold approvals. Agents
build packages, run local tests, analyze supplied evidence and independent durable
readback. Raw captures stay in durable private storage with verified digest/locator;
Git receives sanitized run identities, provenance, metrics and outcomes only.
No game control, saves, station feature, minds, recipient visibility or mutation is
authorized by this replan. No source-resolvable question is assigned as owner research.
