## Shared Patterns

### Strict Lua boundary

**Sources:** `live_galaxy_x4_discovery.lua:9-12, 77-88`; `live_galaxy_telemetry.lua:7-25`.

Use injected APIs, `pcall` around every X4/native boundary, named collection/string limits, and explicit error strings. Do not let native values drive allocation or iteration before validation.

### Canonical facts and serialization

**Sources:** `live_galaxy_normalize.lua:15-68, 70-104, 111-156`.

```lua
local function sorted_unique(items, key)
    if type(items) ~= "table" or #items < 1 or #items > MAX_RUNTIME_FACTS_PER_CLASS then
        return false
    end
    local previous
    for _, item in ipairs(items) do
        local current = item[key]
        if not valid_entity_id(current) or (previous ~= nil and previous >= current) then
            return false
        end
        previous = current
    end
    return true
end
```

Lua sorts candidates before serialization; Rust independently validates relationships, bounds, IDs, and strict unknown fields. Keep the existing compact `s/x/c/o` envelope and do not introduce a second schema.

### Atomic Rust admission

**Sources:** `crates/observation-ingest/src/batch.rs:49-92, 112-135, 138-182`; `runtime_facts.rs:88-126`.

```rust
let mut candidate = accepted.snapshot.clone();
// validate and apply to candidate
match outcome {
    Ok((snapshot, runtime_facts)) => AdmissionOutcome::Accepted(
        AcceptedProjection::with_runtime_facts(snapshot, runtime_facts),
    ),
    Err(error) => AdmissionOutcome::Rejected {
        projection: accepted.record_rejection(RejectionReason::from(&error)),
        evidence,
    },
}
```

Rejected or incomplete component batches preserve the prior accepted projection. A complete marker reconciles only the observed same-version members; no marker means no membership deletion.

### Telemetry-only runtime/reconnect

**Sources:** `live_galaxy_runtime.lua:101-132, 157-167`; `x4_discovery_contract.lua:294-337`.

Preserve hello/generation/sequence, runtime-health fallback, discarded failed writes, and reconnect. Component discovery must not add report, acknowledgement, command, effect, persistence, model, or player UI paths.
