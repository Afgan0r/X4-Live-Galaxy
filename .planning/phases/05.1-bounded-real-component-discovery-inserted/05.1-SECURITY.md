# Phase 05.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
| --- | --- | --- |
| X4 native API → Lua adapter | Native count, fill, identity, metadata, and capacity values remain untrusted until bounded validation succeeds. | Native identifiers and component facts |
| Lua adapter → telemetry serializer | Only a complete, canonical owner-scoped station result may enter the existing one-way telemetry frame. | Bounded observation facts and completion marker |
| Serialized telemetry → Rust admission | Rust independently validates identity, order, relationships, and complete-scope reconciliation. | Untrusted telemetry envelope |
| Disposable probe → evidence ledger | Human-operated runtime evidence is retained only as bounded, class-only diagnostics. | Sanitized attempt metadata |

## Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation | Status |
| --- | --- | --- | --- | --- | --- | --- |
| T-05.1-01 | Denial of service | native station enumeration | high | mitigate | Validate the raw count and hard bound before allocation, conversion, or component reads. | closed |
| T-05.1-02 | Tampering | component identities and Lua-to-Rust facts | high | mitigate | Lua canonicalization plus independent strict Rust identity, order, and relationship rejection. | closed |
| T-05.1-03 | Tampering | complete-scope reconciliation | high | mitigate | Suppress the completion marker on partial or unsupported discovery; rejected batches preserve the accepted projection. | closed |
| T-05.1-04 | Elevation of privilege | telemetry package surface | high | mitigate | Preserve the one-way protocol and enforce the fixed production allowlist with the package guard. | closed |
| T-05.1-05 | Information disclosure | disposable diagnostics | medium | mitigate | Record bounded class-only results without raw IDs, payloads, native errors, prompts, or hidden reasoning. | closed |
| T-05.1-06 | Tampering | station owner scope | high | mitigate | Require every discovered owner to equal the predeclared faction scope before observation construction. | closed |
| T-05.1-07 | Tampering | owner-mismatch reconciliation | high | mitigate | Emit health-only frames with no completion marker; strict Rust admission preserves the prior projection. | closed |
| T-05.1-08 | Elevation of privilege | component discovery scope | high | mitigate | Keep dispatch on the fixed station path and reject foreign owners instead of widening the scope. | closed |
| T-05.1-SC | Tampering | package installs | high | accept | No package installation is planned or performed in Phase 05.1. | closed |
