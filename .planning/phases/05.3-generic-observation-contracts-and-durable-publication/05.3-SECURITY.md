# Phase 05.3 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
| --- | --- | --- |
| Carrier to strict observation envelope | Untrusted carrier bytes become typed observation messages. | Bounded JSON messages, identities, epochs, digests, and versions |
| Strict envelope to candidate state | Decoded batches enter volatile staging and resource accounting. | Records, completion certificates, frozen dependencies, and work charges |
| Candidate to validated authority | Completion attempts to authorize a durable observation revision. | Canonical records, evidence axes, manifests, and content digests |
| Validated authority to repository | A live validated revision enters conditional durable publication. | Typed publication request, expected pointer, dependencies, and acceptance time |
| SQLite to recovery and readers | Durable rows are reopened, integrity-checked, hydrated, and retained. | Revisions, receipts, current pointers, decision pins, and recovery state |
| Observation facade to future carrier | The public carrier vocabulary constrains future X4 integration. | Complete messages, connection state, and bounded control feedback |
