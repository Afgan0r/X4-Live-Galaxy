<interfaces>
Existing contracts to compose without weakening:
- `decode_complete_message(&[u8], usize) -> Result<CompleteMessage, EnvelopeDecodeError>` performs whole-message size-first strict decode.
- `StopAndWaitSlot::{empty, stage_batch, mark_local_handoff, apply_disposition}` retains exact application identity and bytes.
- `GenerationStager::{start_section_with_context, stage_section_batch, completion_certificate, complete_section}` owns keyed volatile candidates.
- `DecisionRevisionIndex::accept(ValidatedSectionRevision, u64) -> Option<AcceptedPublication>` is the revocable accepted-publication authority.
- `PublishRequest::from_accepted(AcceptedPublication)` is the only repository request constructor.
- `ObservationRepository::publish(PublishRequest) -> PublishOutcome` is implemented by the fake and SQLite adapters.

New public composition surface:
- `ObservationLifecycle<R: ObservationRepository>` owns one slot, one stager, one decision index, and one repository.
- `LifecycleInput` binds one immutable application batch to message-specific `LifecycleContext`, injected work, and monotonic time.
- `LifecycleContext` has exact `Start(CandidateContext)`, `Batch`, and `Completion(CompletionCurrent)` variants; a decoded/context mismatch is terminal rejection.
- `LifecycleResult` exposes `DeliveryStage`, `ReceiverDisposition`, and `SlotTurnover` without exposing raw rejected bytes.
</interfaces>
</context>
